# PINK BERRY CLOUD

架空の期間限定ベリーヨーグルトドリンクのランディングページです。
デザイン・Web制作のポートフォリオとして制作しています。

公開サイト：https://amelie-nagisa.github.io/pink-berry-cloud-site/

## 表示方法

リポジトリをダウンロードし、`index.html`をブラウザで開いてください。
画像を表示するため、`images`フォルダーは同じ階層に置いてください。
ビルドや依存パッケージのインストールは不要です。

## 内容

- HTML・CSS・JavaScriptを1つの`index.html`に収録
- モバイルの縦長LPと、PCの左右固定・中央スクロール
- ベリーと透明なシャボン玉の浮遊・スクロール出現演出
- 数量変更と確認画面付きの注文デモ
- キャンペーンの応募方法を案内するモーダル
- キーボード操作と動きを減らす設定への対応

実際の商品販売、注文、決済、キャンペーン応募、抽選、賞品提供は行いません。

## ファイル

- `index.html`：LP本体
- `images/`：オリジナル画像素材
- `design/`：1本のLPを前半・後半に分割した参考カンプ
- `spec.md`：制作仕様書
- `IMPLEMENTATION_PLAN.md`：実装計画
- `IMPLEMENTATION_NOTES.md`：実装内容・動作確認の記録

参考カンプはページ全体の画像として使用せず、各セクションをHTML・CSSで構築しています。
